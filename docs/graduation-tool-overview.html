卒業制作｜ツール概要（最新）

資格の勉強を、自分専用の「問題集＋先生役のAI」で進めるツール

画面は実際のアプリから撮ったイメージです。細部のレイアウトは今後変わることがあります。

ひとことで言うと
学びたい資格を登録し、例題づくり・質問・単語の理解確認・間隔反復の復習・弱点分析・模擬試験までを、ひとつの道具の中で続けられる勉強ツールです。

なぜ作ろうとしているか

背景 今年度中に有効期限が切れる資格があり、その再取得を効率よく進めたい、というのが出発点です。

このツールの強み

強み 1

勉強の流れが一本につながる

  • 問題を解く
  • その問題について質問する
  • 出てきた単語の理解度を確認する
  • 忘却曲線に沿って復習する
  • 弱点を可視化して次の一手を決める

別々のアプリやノートを行き来せず、同じ場所で一貫して続けられます。

強み 2

合格だけでなく、仕事で使うことも見据える

ただ試験に受かるためだけでなく、取得後に現場で判断できるようになることを意識しています。

特に「単語の理解度チェック」で確認します。
たとえば「データを置くサービスの名前」を暗記するだけでなく、 お客様の要望を踏まえて、どのサービスを選ぶべきか まで自分の言葉で説明できるかを、AIに見てもらいます。

フィードバックを受けて追加した機能

経緯 基本機能（例題・AI質問・自力説明・模擬試験）を実装したあと、AIからのレビューを受けて「定着」「現在地の可視化」「生成物の品質担保」が足りないと判断し、以下を追加しました。
A
追加機能

間隔反復（エビングハウスの忘却曲線）に基づく復習

Ankiのような分散学習です。一度説明できたキーワードや、解いた例題も、人間はすぐ忘れる前提で「3日後」「1週間後」などに自動で再テストします。

なぜ追加したか せっかく「自力説明」や「逆引き問題」をやっても、復習の仕組みがないと実用的な定着に結びつきにくい、という指摘への対応です。
画面イメージ｜「今日の復習」モーダル（ヘッダーの件数バッジから開く）
B
追加機能

弱点・理解度の可視化ダッシュボード

履歴の一覧だけでなく、「ストレージ系は80%だがネットワーク系は30%」「説明できたキーワード数：15/50個」といった現在地を、レーダーチャートと進捗率で一目で見られます。全体／月次／週次の切り替えにも対応しています。

なぜ追加したか 「何をしたか」は履歴で見えるが、「今どこが弱いか」が一目でわからないと、次に何を勉強すべきか決めづらく、モチベーションも続きにくい、という指摘への対応です。
画面イメージ｜「分析」モーダル（カテゴリ理解度＋キーワード進捗）
C
追加機能

AI生成コンテンツのユーザーフィードバック機構

例題カードの「誤りを連絡」から、問題文・選択肢・解説・その他を選んで報告できます。サブエージェントレビューを入れても、生成問題の不備（正解が2つある等）をゼロにはできない前提の安全弁です。

なぜ追加したか 生成物の品質をレビューだけで保証しきれないため、ユーザーが「おかしい」と報告し、修正・再学習につなげる仕組みが必要、という指摘への対応です。
画面イメージ｜「内容の誤りを連絡」モーダル

本番試験まわりの現状

実装の進め方（現状） 汎用的に「どの資格でも本番試験を自動生成する」機能は、まだ未実装です。一方で、自分の資格向けの本番試験問題を用意し、受験できるところまでは進めています。受験後の問題は例題に追加できます。
できていること

手元の資格向け本番試験

  • メイン画面の「本番試験を実施」から受験できる
  • 受験し終わった問題を例題に追加できる
  • 自分の資格の問題は作成済み（ただしまだ解いていない分もある）
まだないこと

汎用の本番試験作成

  • 任意の資格向けに本番試験を一括生成する仕組み
  • 受験後の得意／苦手分野分析の見た目確認（残課題）
  • 実施履歴への本番試験結果反映の見た目確認（残課題）

残りの対応

これから確認・仕上げること 本番試験を実際に受験したあと、結果画面と履歴の見え方を確認する必要があります。
残

得意分野・苦手分野の分析結果

本番試験受験後に表示される分野別の分析結果の見た目・内容を確認する。

残

実施履歴の見た目

本番試験の結果が実施履歴にどう載るか、詳細画面の見え方を確認する。

いま見返せるもの（履歴）

  • 例題をまとめて解いた結果
  • 例題でAIに質問した内容
  • 単語の理解度チェックで入力した内容と、AIからのフィードバック
  • 本番試験（模擬）の結果（見た目の最終確認は残課題）

「いつ・何をして・どうだったか」をあとから振り返れるようにしています。
