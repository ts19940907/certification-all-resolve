AIフィードバックを受けて追加した機能

経緯 基本機能を実装したあと、AIレビューで「定着」「現在地の可視化」「生成物の品質担保」が足りないと判断し、次の3つを追加しました。
A
AI指摘 → 追加

間隔反復（エビングハウスの忘却曲線）に基づく復習

Ankiのような分散学習です。一度説明できたキーワードや解いた例題も、忘れる前提で「3日後」「1週間後」などに自動で再テストします。ヘッダーの「今日の復習」から開始します。

なぜ追加したか 「自力説明」や「逆引き問題」をやっても、人間はすぐ忘れる。再テストの仕組みがないと実用的な定着に結びつきにくい、という指摘への対応です。
画面イメージ｜「今日の復習」モーダル（件数バッジから開く）
B
AI指摘 → 追加

弱点・理解度の可視化ダッシュボード

履歴だけでなく、「ストレージ系は80%だがネットワーク系は30%」「説明できたキーワード数：15/50個」といった現在地を、レーダーチャートと進捗率で一目で見られます。全体／月次／週次の切り替えに対応しています。

なぜ追加したか 「何をしたか」は履歴で見えるが、「今どこが弱いか」が一目でわからないと、次に何を勉強すべきか決めづらく、モチベーションも続きにくい、という指摘への対応です。
画面イメージ｜「分析」モーダル（カテゴリ理解度＋キーワード進捗）
C
AI指摘 → 追加

AI生成コンテンツのユーザーフィードバック機構

例題カードの「誤りを連絡」から、問題文・選択肢／正解・解説・その他を選んで報告できます。サブエージェントレビューを入れても、生成問題の不備（正解が2つある等）をゼロにはできない前提の安全弁です。報告をきっかけに修正・再学習につなげます。

なぜ追加したか 生成物の品質をレビューだけで保証しきれないため、ユーザーが「おかしい」と報告し、修正・再学習につなげる仕組みが必要、という指摘への対応です。

追加対応

本番試験（手元の資格向け）

実際の試験に近い制限時間で回答時間を管理し、好きなタイミングで好きな問題を解けます。受験し終わった問題は例題に追加できます。詳細は次セクション。

本番試験の現状

実装の進め方（現状） 汎用的に「どの資格でも本番試験を自動生成する」機能は、まだ未実装です。自分の資格向けの本番試験問題を用意し、受験できるところまでは進めています。問題は作成済みですが、実際にはまだ解いていない分もあります。
できていること

手元の資格向け本番試験

  • 「本番試験を実施」から受験できる
  • 実際の試験に近い制限時間でタイマー管理
  • 好きなタイミングで好きな問題を解ける（番号ナビ）
  • 途中でも採点して終了できる
  • 受験し終わった問題を例題に追加できる
  • 自分の資格の問題は作成済み
まだない／未確認

汎用化と見た目の確認

  • 任意の資格向けに本番試験を一括生成する仕組み
  • 受験後の得意／苦手分野分析の見た目確認
  • 実施履歴への本番試験結果反映の見た目確認
